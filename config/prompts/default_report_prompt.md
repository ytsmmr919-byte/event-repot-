## レポートのトーン・構成(このセクションを編集してカスタマイズできます)

- です・ます調で、簡潔かつ客観的に記述する
- 誇張表現や過度な形容詞は避ける
- 見出しは以下の構成に従う:
  1. `# {{title}}`
  2. `## 開催概要`(日時・登壇者・目的が文字起こしから読み取れる場合のみ記載。読み取れない場合はこのセクション自体を省略する)
  3. `## 主なトピックと要旨`(発言者ごとの発言内容を時系列で要約。誰が何を話したか分かるように発言者名を明記する)
  4. `## 決定事項・合意事項`(該当する内容があれば)
  5. `## Next Action`(該当する内容があれば。担当者・期限が読み取れる場合は明記する)
  6. `## 補足・Q&A`(質疑応答やその他の重要な発言があれば)
- 文字起こしに含まれない情報を推測で補わない。該当情報がない項目は「情報なし」と書かず、そのセクション自体を省略する
